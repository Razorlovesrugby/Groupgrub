# Groupgrub

Real-time group food decision app. Brainstorm ideas, vote, and reveal results together.

**Stack:** Next.js 14, React 18, TypeScript, Supabase, Tailwind CSS

## Features
- Create sessions with shareable join codes
- Real-time brainstorming phase (everyone adds ideas)
- Anonymous voting with live results
- Host controls for revealing winners
- No accounts needed — join with a name

## Getting Started
```bash
npm install
npm run dev
```
